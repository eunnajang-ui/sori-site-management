# 업무 규칙 — 화면 숫자를 만드는 기준

## 1. 사업 구조

| | 미군부대 공사 (상무님 현장: 동두천·평택 등) | 미군부대 공사 (군산) | 국내 관급공사 |
|---|---|---|---|
| 돈 흐름 | 계약(NTP) → 인보이스 → 입금 → 상무님 기성 → 확인·결재·지급 → 준공·정산 | 계약 → 인보이스 → 입금 → 본사 지출결의서 → 준공 | 계약 → 선금 → 노무비·기성 청구(하도급지킴이) → 발주처 승인 → 입금·하도급 직불 → 준공·정산 |
| 정산 | 상무님 「기성금 분석」 방식 | 본사 직영 (받은 돈 − 지출) | 지출결의서 / 현장별 통합정산 |
| 퇴직공제 | 없음 | 없음 | 있음 |

## 2. 미군(상무님 현장) 정산

- 공사금액(상무님 몫) C = 총공사금액 F ÷ (1 + 요율)
- 본사 몫 E = C × 요율 (요율은 상무님 분석표 기성 줄 기준. 예: 7%. 계약 줄 8.5%와 다를 수 있음)
- 수령금액 G = **실제 입금액**
- 지급금액 H = G − E
- 결의서 미집행 = 직전 차수 미집행 + H − 업체 지급(공급가) 합계 − 공제 합계
- 준공 차수: 하도급금액 × 1.5% 산재보험료 추가 공제
- 지연이자는 본사 몫 (분석에 넣지 않음)
- 준공 전에 남은 돈은 다음 차수로 넘어가고, 준공하면 끝

### 0.51%는 무조건 공제가 아니다

- 인보이스에 적는 **조기지급 할인 조건** (예: "DISCOUNT Terms: 0.51 Discount may be taken NTL 10 days…", "Request 0.51% discount for prompt payment within 10 days")
- 미군 지급처가 인보이스를 받고 **10일 안에 지급하면 0.51%가 빠지고**, 늦게 지급하면 **전액** 입금
- 할인 조건이 없는 인보이스도 있음
- 입금 전에는 0.51%를 미리 빼지 않는다. 입금되면 실제 금액으로 판단

## 3. 국내 공사

- 계약금액(당사 몫) = 총공사(부기)금액 × 당사 지분 (공동도급)
- 받은 돈 = 발주처 청구 합계 (VAT 포함). 하도급 직불은 하도급사로 바로 나가 당사 통장에 안 들어옴
- 공동도급: 대표사가 청구, 당사는 하도급지킴이에서 지분만큼 승인
- 원도급: 하도급사 청구를 먼저 승인한 뒤 당사 기성청구에 합쳐 송신
- 채권 = 공급가 × 2.5%, 5천원 단위 올림
- 금액 기준은 홈택스 세금계산서(승인번호)

## 4. 화면 표시 기준

- **단계:** 1 계약·착공 준비 / 2 기성 전(인보이스 전) / 3 기성 진행(인보이스 나감·입금 진행) / 4 준공·정산 마무리(준공금 입금, 마지막 정산 남음)
- **미집행:**
  - 국내: 최근 지출결의서 값. 현장별 통합정산(홈택스 기준) 파일이 있으면 그 값
  - 미군(상무님): 상무님 기성 지출결의서 값만. 없으면 "상무님 기성 정산 전"(받은 돈 있음) / "입금 전(인보이스 나감)" / "기성 전"
  - 군산: 받은 돈 − 결의서 지출
- **미군 청구·입금:** 공사대장 "4. 인보이스" 폴더 파일명으로 확인 (파일명 앞 "YYYY.MM.DD입금" = 입금된 것)
- **진행 현장만 표시.** 준공·정산이 끝난 현장은 뺌
- 원자료로 확인 안 되는 값은 "확인필요"
