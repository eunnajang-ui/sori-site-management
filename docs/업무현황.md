## 사업 구조

미군부대 공사와 국내 관급공사는 청구·입금·정산 방식이 달라, 같은 담당자가 두 가지 흐름을 동시에 관리합니다.

- **미군부대 공사:** 계약·NTP → 인보이스(차수별 청구) → 입금(조기 지급 시 0.51% 할인) → 상무님 기성(확인·결재·지급) → 준공·정산. 군산 현장은 본사 직영으로 지출결의서로 바로 정산. 미군은 퇴직공제 없음
- **국내 관급공사:** 계약(원도급·공동도급) → 선금(보증·채권) → 노무비·기성(하도급지킴이) → 발주처 승인(입금·하도급 직불) → 준공·정산. 공동도급은 대표사가 청구하고 당사는 지분만큼 승인·정산

미군 상무님 현장은 공사금액 = 총액 ÷ (1+요율)로 본사 몫을 나누고, 준공 전 남은 돈은 다음 차수로 넘어갑니다. 0.51%는 인보이스에 적는 조기지급 할인 조건이라, 미군이 인보이스를 받고 10일 안에 지급할 때만 빠지고 늦게 지급되면 전액이 들어옵니다. 할인 조건이 없는 인보이스도 있습니다.

## 어려운 점

가장 큰 문제는 같은 금액이 여러 양식에 따로 입력되고, 그사이 어긋난 값을 사람이 눈으로 찾아야 한다는 점입니다.

1. **같은 숫자를 여러 번 입력:** 기성 한 번에 정산서·지출결의서·매입매출장·급여·4대보험 정산내역·신용장 List에 각각 넣음
2. **자료가 흩어져 있음:** 공유폴더, 홈택스, 하도급지킴이, 나라장터, 회사 메일, 상무님 서류가 서로 연결돼 있지 않음
3. **로그인이 필요한 사이트:** 홈택스·하도급지킴이·공단 사이트는 인증서 로그인이 필요해 완전 자동화가 어려움
4. **현장마다 다른 정산 방식:** 미군은 상무님 기성·요율, 10일 안에 지급될 때만 빠지는 0.51% 조기지급 할인, 군산은 본사 직영, 국내는 공동도급 지분·하도급 직불이 섞임
5. **급여가 여러 현장으로 나뉘어 정산:** 같은 지역 급여를 어느 현장·차수에서 공제할지 그때그때 정해져 추적이 어려움
6. **공용 엑셀을 여러 곳에서 고침:** 예전 사본이 덮어써져 입력이 사라진 일이 있었음
7. **최신본이 멈춤:** 정리 파일이 사람이 요청할 때만 갱신돼 새 인보이스가 빠진 적이 있음

## 요청 사항

1. **현장 마스터 + 자동 연결:** 현장·계약 정보를 한 곳에 두고 회사 양식에 넣을 값을 자동으로 만드는 구조
2. **서류 대조 에이전트:** 기성 서류·인보이스·세금계산서·통장·하도급지킴이 금액을 자동 대조해 "맞음 / 고칠 것 / 확인할 것"으로 보고
3. **회사용 현장관리 화면 정식화:** 대표님 견적·제안 시스템(수주까지)과 이어지는 수주 이후 화면. 단계: 계약 → 착공·신고 → 공사 중 → 준공 → 정산·마감, 현장별 체크리스트
4. **로그인 사이트 연동 방법:** 사람은 로그인만 하고 나머지는 자동으로 읽어 오는 방식
5. **공용 파일 저장 안전장치:** 여러 사람이 함께 써도 입력이 사라지지 않는 저장 구조(또는 데이터베이스)
6. **업무 지침·교육:** 다른 직원도 같은 방식으로 쓸 수 있도록 업무별 지침과 사용법 정리
