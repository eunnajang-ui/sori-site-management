# 데이터 구조 (`data.json`)

화면은 `template.html` 하나에 `data.json` 을 넣어 만든다 (`site/make_page.py`). 예시는 `site/sample_data.json`.

```
{ "asof": "기준일", "dom": [국내 현장...], "us": [미군 현장...], "jchk": [하도급지킴이 확인할 것...], "checks": [확인할 것...] }
```

## 국내 현장 (`dom[]`)

| 항목 | 뜻 | 원자료 |
|---|---|---|
| key, 공사명, 발주처, 구분(원도급/공동도급), 대표사, 지분, 구성 | 현장 기본 | 국내공사_현장통합관리.xlsx 「현장마스터」 |
| 총공사, 당사몫, 기간, 준공예정, 하도급사, 상태, 비고 | 계약 | 「현장마스터」·「현장현황」 |
| stage | 화면 단계 1~4 | 규칙 (docs/업무규칙.md) |
| 청구누계, 청구율, 선급금, 노무비, 기성준공, 직불, 최근청구(일) | 받은 돈 | 「현장현황」·「청구대장」 |
| 결의총기성, 결의집행, 미집행, 미집행근거 | 정산 | 최근 지출결의서 / 현장별 통합정산 |
| 상용급여, pay[[월, 금액]], ilyong[[월, 금액]] | 급여 (월·현장 합계만) | 「급여배분」·노임 집계표 |
| claims[] | 청구 1건 1줄 (구분·내용·청구일·공급가·세액·합계·입금일·입금처·당사입금·직불·확인) | 「청구대장」 |
| jik[] | 하도급지킴이 현장별 요약 (계약·청구누계·당사수령·직불·지킴이 지급·하도급 계약/수령) | 하도급지킴이_관리.xlsx 「현장별 요약」·「하도급계약」 |
| subs[] | 하도급사별 계약·지급 | 「하도급사」 |
| tax.buy / tax.sell / tax.bank | 현장 지정된 매입·매출 세금계산서, 통장 입출금 합계 | 세금계산서_통장_통합대장.xlsx 「매입」「매출」「통장」 |

## 미군 현장 (`us[]`)

| 항목 | 뜻 | 원자료 |
|---|---|---|
| key(계약번호), short, region, group(상무님/본사), 공사명 | 현장 기본 | 미군현장_통합관리 「현장목록」 |
| 계약, 하도급금액(상무님 몫), 요율, 기간 | 계약 | 회사 정산서 앞장 |
| gisung[] | 차수별 인보이스·청구·0.51% 할인(실제)·실입금·입금일·통장 일치 | 4. 인보이스 폴더 파일명 + 통장 |
| 청구누계, 실입금 | 합계 | gisung 합 |
| gongje[[항목, 금액]], 지출, 지출근거 | 나간 돈 | 정산서 공제 (원도급 지급자재·직원급료·임금) / 군산은 지출결의서 |
| 미집행, 미집행근거 | 정산 | 상무님 기성 지출결의서 |
| LC, 외자재원화, fx[] | 외자재 (L/C·B/L·수수료) | 외자재 신용장 개설 List |
| sal[[월, 구분, 금액]] | 급여 정산 (월·현장 합계) | 급여배분 |
| tax | 2026년 현장 지정 매입·통장 출금 | 세금계산서_통장_통합대장.xlsx |
